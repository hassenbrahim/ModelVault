# ModelVault

A simple ModelVault Server for Auto scaling capabilities.

With ModelVault, you get a lightweight tool that stays out of your way.

**What you get**

- A simple ModelVault Server for Auto scaling capabilities

## Key Features

- A simple ModelVault Server for Auto scaling capabilities

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ModelVault.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ModelVault is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
